# DetektifBilangan
Media pembelajaran interaktif untuk siswa kelas 5 SD ini mengajak siswa menjadi detektif bilangan. Melalui empat misi, siswa mengenali bilangan prima dan komposit, mencari pasangan faktor, menguraikan bilangan dengan pohon faktor, lalu menguji pemahamannya lewat kuis. Di akhir, siswa melihat laporan rangkuman materi.
